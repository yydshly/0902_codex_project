## 素材检查

- [ ] 文件名稳定、语义明确，不包含临时编号。
- [ ] README 中的 `alt` 文本准确描述画面。
- [ ] 已说明素材支持的结论，而不只是复述画面。
- [ ] 已记录来源、许可证或引用边界。
- [ ] 外部界面已记录截取日期。
- [ ] 图片不包含密钥、个人信息或无关浏览器内容。
- [ ] 封面经过合理压缩；默认优先使用 WebP、AVIF、PNG 或 SVG。
