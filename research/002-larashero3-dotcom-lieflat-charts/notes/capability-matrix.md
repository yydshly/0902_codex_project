# Lieflat Charts 能力矩阵

本页基于上游 commit [`4eef5ce`](https://github.com/larashero3-dotcom/lieflat-charts/tree/4eef5ce00d0907a03b8eff42578b5a04942915e9)，用于回答“它目前真的能做什么”。数量以该版本的 `catalog.md` 和实际文件为准。

## 1. 图型能力

| 体系 | 数量 | 阅读方式 | 代表数据形状 | 典型场景 | 主要技术 |
| --- | ---: | --- | --- | --- | --- |
| Glance（G1–G22） | 22 | 3–10 秒快读，先聚合再给结论 | 区间、排名、正负、占比、实时流、动态排名、矩阵、聚合流量 | 周报、dashboard、监控、汇报 | ECharts、Chart.js、SVG |
| Lupi Editorial（L1–L20） | 20 | 30 秒以上细读，尽量保留逐条记录 | 逐记录分布、事件生命史、多对一归属、日历热力、山脊图、平行坐标 | 年报、研究报告、长文、海报 | 手写 SVG |
| Lupi Basics（F1–F17） | 17 | 熟悉轮廓 + 可数单位 | 柱、线、面积、环形、散点、瀑布、热力、仪表、箱线、K 线 | 稀疏数据、业务复盘、分析附图 | SVG；Treemap 用 ECharts |
| Maps（M1–M2） | 2 | 区域着色 | 美国州级、世界国家级非负数值 | 地域分布 | ECharts + 在线 GeoJSON |
| Big（B1–B3） | 3 | 逐节点或逐路径查询 | 环形网络、力导向网络、多段流向 | 高密度关系数据 | ECharts、手写 SVG |

### 数据形状覆盖

- 比较与排名：少类目、多类目、正负、前后对比、随时间排名。
- 时间：日序列、区间、累计、实时滚动、全年日历、OHLC。
- 构成与流量：100% 构成、堆叠、漏斗、Treemap、Sankey、多段路径。
- 分布：散点、抖动条、蜂群、直方图、箱线图、小提琴、山脊图。
- 关系：树、矩阵、多对一归属、网络、平行坐标。
- 空间：美国州级和世界国家级 choropleth；其他地图范围不在现成能力内。

## 2. 视觉与交互能力

| 能力 | 已有实现 | 约束 |
| --- | --- | --- |
| Mono | 纸灰 / 炭黑两极与 7 级灰阶，明度承担层级 | 无渐变、无发光、无装饰性阴影 |
| Porcelain | 单色相青瓷蓝明度梯 | 适合有序数据、单序列 |
| Palm | 低饱和绿黄分类色 | 适合不超过 4–6 个无序类目 |
| Wire | 灰阶 + 单一荧光橙重点 | 强调色只能给一个主角 |
| Custom | 根据用户品牌色建立完整语义角色 | 只在用户明确给色时启用，不与内置预设混用 |
| 入场与重播 | IntersectionObserver 滚入播放，点击重播 | 动效不能改变数据结构 |
| 高密度查询 | hover 单项、hover 整束、点击钉住、状态栏 | 只给真实记录添加交互 |
| 动态演示 | scatter morph、bar race、dynamic stream、counter | 演示动画不等于真实数据连接 |

## 4. 能力边界

| 看起来像 | 实际上是 | 缺失能力 |
| --- | --- | --- |
| 图表库 | Agent skill + 模板集 | npm API、React / Vue 组件、稳定 schema |
| 实时大屏 | 本地定时器驱动的动态图例 | WebSocket、流处理、实时数据适配器 |
| BI 工具 | 有编辑感的最终表达层 | 查询、清洗、指标治理、权限与钻取平台 |
| 离线 HTML | 多数页面可直接打开 | 部分 CDN、字体、GeoJSON 仍需内联 |
| 自动生成器 | Agent 读规则后复制与替换模板 | 独立 CLI、确定性编译器、机器可验证选型 |

## 5. 可扩展方向

1. 把 `catalog.md` 变为机器可读的 `ChartIntent` / JSON Schema，并实现真正的 `data + spec → HTML/SVG` 编译器。
2. 拆分大 gallery 为独立图型模块，建立 renderer adapter 和模板注册表，减少彩色变体复制。
3. 增加 CSV、Excel、SQL、API、流式数据适配器与语义数据校验。
4. 锁定依赖版本，提供离线 bundle、SRI、CSP 和不可信文本转义。
5. 用 golden screenshot 做视觉回归，并补齐键盘、ARIA、触控与 reduced-motion。
6. 增加 PNG / PDF / PPT 导出、品牌主题、更多语言与合规地图数据源。
7. 建立 Agent 选型评测集，测量选型准确性、数值保真和重复图控制能力。
