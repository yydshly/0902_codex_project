# Yichen Skills Capability Atlas

一个零依赖静态网页，用于完整呈现 `mcncarl/yichen-skills` 的 22 个 Skill、四层运行原理、适用场景、风险边界与团队价值，并把分析推进到“我们是否采用、如何真实试用、何时沉淀为自有 Skill”。

## 交互内容

- “阶段性结论”用一屏说明它的本质、执行主体、真正价值、非目标和按需使用停止条件。
- 22 个 Skill 均提供独立典型场景、输入输出、底层机制、依赖、边界和可借鉴价值。
- 22 项能力被逐项放入“方法借鉴 / 个人试用 / 授权后重写 / 暂不采用”四类决策矩阵，每项都说明理由和下一步。
- “内容创作闭环”用 7 步展示研究、搜索、归档、ASR、内容拆解、草稿/切片与记忆沉淀。
- 还可切换“深度研究闭环”和“私域资产闭环”，比较不同授权与交接方式。
- 流程支持手动选步、自动播放、完成态、重置和键盘切换；reduced-motion 下立即展示完成态。
- “真实试用台账”可记录任务、耗时、人工介入、结果、完成证据和问题；记录只保存在当前浏览器，可统计、导出 JSON 和逐条删除。
- 七段式设计卡与四道升级判断门，用于把多次有效试用重写为我们的 Skill，而不是直接复制上游实现。
- 流程模拟器中的运行数量与结果都是明确标注的说明性样例，不会调用任何真实平台。

当前使用原则是“遇到真实任务再查、选择低风险方式体验、多次有效再独立沉淀”。无需试遍全部 22 个 Skill，也不把研究覆盖率当成目标。

## 本地运行

```powershell
npm ci
npm run check
npm run build
npm run dev
```

浏览器打开 `http://127.0.0.1:4177/`。构建产物输出到 `dist/`。

## 事实边界

- 研究基线固定在上游提交 `14f10a96a719a1d60aa02c582e674d5b197d5861`。
- 22 项指 21 个根目录 `SKILL.md` 加 1 个插件内部 `SKILL.md`；其中 `yichen-social-bookmarks-exporter` 是退役兼容入口。
- 实现层级 P / B / E / V / D 是本项目的分析标签，不是上游官方评级。
- 页面没有调用上游服务，也不会读取登录态或私人数据；试用台账只写当前浏览器 `localStorage`，用户可主动导出 JSON。
- 流程演示用于解释 Skill orchestration，不是上游执行日志或真实性能基准。
- 台账由用户填写真实任务证据，和页面内置的说明性流程样例严格区分；不要在台账中填写密钥、凭据或私人原文。
- 上游许可证限定个人学习和非商业使用；企业复用前需获得授权或独立重写。

完整研究材料位于 `research/005-mcncarl-yichen-skills/`。
