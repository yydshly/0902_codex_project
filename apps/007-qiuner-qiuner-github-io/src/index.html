    03 / RUNTIME

    Shared Runtime

    全站只有一个 renderer 和一个 RAF；任务按阶段执行，页面隐藏时统一暂停。

    ONE RENDERER · ONE CLOCK
    04 / JOURNEY

    Atomic Portal

    目标安装成功后才提交 URL 与所有权；失败、取消或快速重入都可以回到来源世界。

    Adaptive Budget
