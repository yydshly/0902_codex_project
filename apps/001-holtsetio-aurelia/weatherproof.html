REAL PRODUCT PIPELINE / 真实商品接入

现在是数字样机；
真实上线，需要四类可信输入。

大模型可以辅助生成概念方向和材质预览，但不能替代产品几何、材料扫描和实验室数据。
  1. 01商品几何

    实物摄影、摄影测量、CAD 或经过优化的 GLB，决定轮廓、开合结构与细节可信度。

    PHOTO / CAD / GLB
  2. 02真实材料

    PBR 扫描、布纹、透明度、粗糙度与雨水状态，让伞面在不同光线下仍像同一件商品。

    PBR / FABRIC SCAN
  3. 03实测响应

    风洞、淋雨、张力与排水曲线校准模拟，使互动解释有产品证据，而不是视觉猜测。

    TEST CURVES
  4. 04业务数据

    PIM/SKU、价格、库存、城市天气与 CRM 把数字孪生连接到推荐、购买和销售跟进。

    PIM / API / CRM
