## 精炼记录

| 观察 | 处理 | 结果 |
| --- | --- | --- |
| 原始上游是 Markdown 图库，不能直接形成产品级检索旅程 | 在不改变素材语义的前提下增加 8×33 总览、全量分组、文本搜索、目录下载和详情层 | 350 项默认全部进入一个网页，仍保留上游边界 |
| 当前 v2 标签错位，普通画廊会把错误映射静默呈现 | 所有卡片标明 `UPSTREAM LABELS · UNVERIFIED`，详情与独立章节重复提醒 | 页面不把目录标签冒充已验证知识 |
| 主题组 `content-visibility` 造成长页面高度变化与末项跳转漂移 | 移除主题组跳过渲染，改用固定卡片几何与显式 `IntersectionObserver` 图片加载 | 页面高度稳定；第 350 项可准确定位，图片仍按接近视口才加载 |
| 350 张图片可能造成首屏请求过多 | 350 张卡片全部进入 DOM，但图片 URL 先保存在 `data-src`，接近视口才赋给 `src` | 首屏不请求图鉴图片，全量结构可检索但不一次性下载全部素材 |
| 桌面两栏详情不适合 390px | 手机断点改为单列、dialog 内部滚动 | 海报、metadata 和关闭按钮均可达 |
