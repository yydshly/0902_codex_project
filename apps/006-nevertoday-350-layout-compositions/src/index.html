WHAT IT ACTUALLY DOES

四层能力，不多算一层

01

知识压缩

把一个构图或版式概念整理成带名称、定义、结构示意与应用提示的教学海报。

02

分类导航

从抽象构图原则延伸到网页 UI、影视、中国传统构图与演示文稿。

03

机器目录

JSON / CSV 提供编号、名称、分类、图片路径、尺寸和 SHA-256，可被程序读取。

04

静态生产

Python 管线生成缩略图、目录和 Markdown 画廊，并验证文件与链接完整性。

没有包含：内容理解、自动版式选择、可编辑模板、CSS / PPT / Figma 输出。

THE IMPORTANT LIMIT

结构正确，
不等于语义正确。

上游验证脚本能确认文件存在、编号连续、哈希一致和链接可用，却没有读取图片内部的大标题。因此一个图片即使被赋予了错误名称，仍然可以通过全部结构检查。
