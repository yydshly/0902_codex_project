# Lieflat Charts 能力展厅 · 交付契约

## 设计契约

```text
Entry mode: Brief-led implementation
Request revision: 8
Target user and context: 不预设图表库、Agent 或前端术语知识，希望用中文快速看懂 lieflat-charts 的读者
Desired first impression: 第一眼先看到“我正在做电商周报、增长复盘、客服分析……”等真实业务任务；选中后立即看到业务目标如何拆成分析问题；运行调用后仍能看见自己从哪个业务问题而来、当前借用什么模板结构以及怎样返回
Visual ambition: Editorial
Experience architecture: Editorial Flow
Visual constraints: 单一浅色主题；编辑式黑白灰界面；仅用橙红作为操作与状态强调；界面中文优先；不覆盖上游样张自身视觉
Information constraints: 事实只基于固定 commit；先展示真实业务场景，再用一张架构与能力总图解释“业务目标和已有数据如何经过 Agent 控制层、规则与模板资产、浏览器渲染层形成 HTML 交付”；总图必须同时标出 64 种图表、12 套报告、4 套视觉系统、三种渲染技术与能力边界，不得暗示存在直接传数据的运行时 API；每个场景必须明确业务目标、输入数据、三个分析调用、所用图表/报告编号及产出；调用结果区必须保留业务上下文，并解释上游样张数据与用户数据不同是因为只复用表达结构；Glance、Lupi 等上游专名只作为次要标识并就近解释
Operation constraints: 零前端依赖；静态构建；相对 URL；鼠标、触控和键盘均可切换业务场景并运行其中一个分析调用；调用后进入真实样张，在可行时定位和强调具体图，并提供回到原调用的明确路径
State constraints: 六类业务场景、场景选中、调用选中、调用深链、最终交付选中、样张内定位、筛选、加载、加载失败、中文、英文和窄屏堆叠均有可理解反馈
Environment constraints: GitHub Pages 子路径；Node.js >=22；上游部分模板依赖 CDN 和网络字体
Primary journey: 默认用纯中文选择正在做的真实业务任务 → 看清该任务需要哪些输入数据 → 理解它被拆成哪三个分析问题 → 看到每个问题调用库中的哪项能力 → 通过一张总图建立“输入—Agent 判断—规则与模板—浏览器渲染—HTML 交付”的完整心智模型 → 一键运行并定位真实样张 → 在结果区保持业务问题、模板和示例边界可见 → 返回业务拆解或继续浏览
User-defined phases: 新建子项目；获取上游；总结能力；展示已有能力；中文化并降低理解门槛；提供中英文整版切换以避免混排污染；补充按业务场景选择效果的决策指南；把抽象系列推荐改为具体问题到具体图表的直接映射；增加一张架构与能力总图
Required artifacts: 研究条目、能力矩阵、静态展示应用、固定上游版本记录、双语响应式架构与能力总图、构建与浏览器验证记录
Autonomy authorization: 用户明确要求新建、获取、总结和展示，并持续指出当前页面的可理解性问题；允许范围内直接实现和验证
User-decision boundary: 不安装为全局 Codex skill；不改上游源码；不引入后端；不主张商业授权
Observable completion criteria: 根目录登记 002；上游 clone 可追溯；应用可构建；默认中文视图直接出现至少六个真实业务任务；每个任务展示业务目标、输入字段、三个调用步骤、对应库能力与最终产出；点击调用进入真实样张并在可行时定位目标图；结果区持续显示来源场景、原业务问题、模板编号、样张数据边界和返回操作；调用状态可随网址恢复；一张总图能在单一阅读流中解释输入、Agent 控制层、规则/目录/token/模板资产、SVG/ECharts/Chart.js 浏览器渲染和单图/报告 HTML 交付，同时标出能力规模与“不是直接数据 API”的边界；总图完整中英切换并在桌面/平板/390px 手机无裁切；键盘可完成原主路径
Coverage record: 下表
```

## 视觉方向

| 决策 | 选择 | 可观察约束 | 验收标准 |
| --- | --- | --- | --- |
| 信息层级 | 真实业务任务先于能力分类和样张浏览 | 首个主区直接给出六个业务任务；选中后同屏看到输入、三次模板调用和最终交付物 | 不需要先懂图表术语，即可从自己的工作找到具体模板，并理解库在链路中的责任 |
| 排版 | 中文无衬线正文 + 等宽元数据 | 标题、说明、版本信息角色清晰 | 390px 到桌面均无裁切和过长行 |
| 色彩 | 暖白、炭黑、中灰、橙红强调 | 颜色不承担唯一语义 | 选中、聚焦和错误状态均有形状或文字辅助 |

| 动效 | 仅状态切换，尊重 reduced-motion | 不新增持续动画 | 关闭动效后功能与信息不减少 |

## 支持边界

- 展厅只负责检索、选择和承载上游样张；图表数据仍是上游示例数据。
- iframe 中的 ECharts、Chart.js、GeoJSON 和 Google Fonts 可能需要外网；展厅外壳本身不依赖它们。
- 上游文件按固定 commit 在构建时获取，产物继续受 PolyForm Noncommercial 1.0.0 及第三方声明约束。
